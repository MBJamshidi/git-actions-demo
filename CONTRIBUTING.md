# Contributing

Thank you for your interest in contributing!

## Workflow

1. Fork the repo and create a branch from `main`.
2. Make your changes with tests.
3. Run `pytest` and `ruff check .` locally — both must pass.
4. Open a Pull Request. The CI pipeline will run automatically.

## Code Style

This project uses [Ruff](https://docs.astral.sh/ruff/) for linting. Run it before committing:

```bash
ruff check .
ruff format .
```

## Reporting Bugs

Use the **Bug Report** issue template on GitHub.

## Suggesting Features

Use the **Feature Request** issue template on GitHub.
